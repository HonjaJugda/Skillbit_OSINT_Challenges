# Skillbit OSINT Challenges Walkthroughs

This repository contains my walkthroughs and methodology for completing the Skillbit OSINT challenges. The purpose of these write-ups is to document the investigative process used to identify, collect, correlate, and validate publicly available information while developing practical Open-Source Intelligence (OSINT) skills.

The walkthroughs focus on real-world OSINT techniques including username enumeration, social media analysis, image intelligence, geolocation, metadata extraction, domain research, and public records investigation.

> **Disclaimer**
>
> These walkthroughs are intended for educational purposes only. All information was obtained from publicly available sources during authorized challenge environments. No intrusive or unauthorized activities were performed.

## Methodology

The methodology used throughout these challenges follows a repeatable OSINT workflow:

1. Information Gathering
2. Source Validation
3. Data Correlation
4. Attribution Analysis
5. Documentation
6. Reporting

Each walkthrough includes the tools used, investigative process, findings, validation steps, and lessons learned.

---

## Key Takeaways

These challenges reinforce the importance of publicly available information and how seemingly unrelated data points can be correlated to build a comprehensive profile of a target. Developing strong OSINT skills enhances reconnaissance capabilities and supports effective security assessments, penetration testing, threat intelligence, and incident response activities.
